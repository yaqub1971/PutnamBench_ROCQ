# putnam_1967_a4 -- notes

Audit verdict: **unfaithful** (the integral is over [0, 1] instead of [x, 1]). On
re-reading, the upstream theorem is in fact **false** as written (section 2), and it
has a second, independent defect (no integrability condition on u). Upstream commit
4dbe26ef21563af851eedaeb82d936fe1f94fc52 of PutnamBench, file `coq/src/putnam_1967_a4.v`.

## 1. The problem

Putnam 1967 A4. Show that if lambda > 1/2 there does not exist a real-valued function u
such that for all x in the closed interval 0 <= x <= 1,
u(x) = 1 + lambda * int_x^1 u(y) u(y - x) dy.
(Classical solution: integrate the equation over x in [0, 1]. With I = int_0^1 u, the
double integral int_0^1 int_x^1 u(y) u(y - x) dy dx equals I^2 / 2 (substitute s = y - x;
the region 0 <= s <= y <= 1 is half of the square), so I = 1 + lambda I^2 / 2, i.e.
lambda I^2 - 2 I + 2 = 0, whose discriminant 4 - 8 lambda is negative for lambda > 1/2.)

## 2. Defect(s) in the upstream statement

The upstream statement (kept verbatim, after a header comment and one compat line, in
`putnam_1967_a4.v`):

```coq
Variable R : realType.
Definition mu := [the measure _ _ of @lebesgue_measure R].
Theorem putnam_1967_a4
    (lambda : R)
    (hlambda : lambda > 1 / 2)
    : ~exists u : R -> R, forall x : R, 0 <= x <= 1 -> u x = 1 + lambda * \int[mu]_(y in [set y | 0 <= y <= 1]) (u y * u (y - x)).
Proof. Admitted.
```

**Defect 1 (the audited one): wrong domain of integration.** The integral is over
`[set y | 0 <= y <= 1]` = [0, 1] instead of [x, 1]. For y in [0, x) the factor
`u (y - x)` evaluates u at negative arguments, which the problem never uses; the values
of u on [-1, 0) become free parameters and the equation becomes a different, much
weaker constraint.

*It makes the theorem false.* A bounded counterexample, for any lambda > 1/2: pick
k < 0 with c := (1 - e^(2k)) / (-2k) < 1 / (4 lambda) (e.g. k = -4 for lambda = 1), let A
be a root of lambda c A^2 - A + 1 = 0, and put

    u(y) = A e^(k y)                              for y >= 0,
    u(z) = k / (lambda A) + A e^(2k) e^(k z)      for z < 0.

For x in [0, 1] split int_0^1 = int_0^x + int_x^1:
int_0^x A e^(ky) (k/(lambda A) + A e^(2k) e^(k(y-x))) dy = (e^(kx) - 1)/lambda + A^2 e^(2k) e^(-kx) (e^(2kx) - 1)/(2k),
int_x^1 A e^(ky) A e^(k(y-x)) dy = A^2 e^(-kx) (e^(2k) - e^(2kx))/(2k);
the A^2 terms add up to c A^2 e^(kx), so
1 + lambda * int_0^1 u(y) u(y - x) dy = e^(kx) (1 + lambda c A^2) = A e^(kx) = u(x).
(For lambda = 1, k = -4: c = (1 - e^-8)/8, A = 1.17149..., u(z) = k/A + A e^(2k) e^(kz);
this is the instance quoted in the header of `putnam_1967_a4.v`.) On [-1, 1], the only
arguments the equation uses, u is bounded and continuous on [-1, 0) and on [0, 1], so
every integrand is bounded and Borel on [0, 1], MathComp-Analysis' integral is the
ordinary one, and the upstream theorem is false for every lambda > 1/2. Checked
numerically (section 4, check 4).

There is also an unbounded counterexample that exploits the junk value of the Rocq
integral (see defect 2): u(0) = 1 + lambda, u = 1 on (0, 1], u(t) = -1/t on [-1, 0).
For x in (0, 1] the integrand u(y) u(y - x) is >= 0 on [0, 1] and equals 1/(x - y) on
(0, x), so its integral is +oo, the Rocq integral is 0 and the equation reads
u(x) = 1; at x = 0 the integrand is u(y)^2 = 1 a.e. on [0, 1], the integral is 1, and
the equation reads u(0) = 1 + lambda. Both hold.

**Defect 2 (found on re-reading): no integrability condition.** In `ring_scope`,
`\int[mu]_(y in D) g y` is MathComp-Analysis' `Rintegral`, the finite part (`fine`) of
the extended-real Lebesgue integral: it is 0 when the integral is +oo or -oo, i.e. for
integrands that are not integrable. The statement quantifies over all u : R -> R, so it
also speaks about functions for which the problem's integral does not exist, and reads
the equation for them as u x = 1 + lambda * 0. The informal equation presupposes that
its integrals exist. PutnamBench's Lean statement guards against this with
`MeasureTheory.IntegrableOn u (Set.Icc 0 1)`.

**Re-reading against the trap list of the brief (section 7.5):** no further defect.

* `lambda > 1 / 2` is in R (Set Printing All under Rocq 9.1 shows
  `GRing.mul (GRing.one _) (GRing.inv (Algebra.natmul (GRing.one _) (S (S O))))`): no
  `nat` division; strict inequality as in the problem.
* `0 <= x <= 1`: the closed interval of the problem, in R.
* `u y * u (y - x)`: the problem's integrand, product (not sum), argument y - x.
* No `pow`/`^`, `Rpower`, `ln`, `Series`, `sum_n`, `sup`, `exprz`, `Q`, `'I_n`, no
  `(h : Prop := ...)` local definitions; `mu` is Lebesgue measure on R (on the
  sigma-algebra generated by the half-open intervals, i.e. the Borel sets, on both
  toolchains: `Check mu`, `About lebesgue_measure`).
* The negated existential `~exists u, ...` is the problem's "there does not exist";
  no existential scopes over a biconditional.
* The theorem name matches the problem; there is no `_solution`.

**Rocq 9.1 compatibility (not a mathematical defect):** `Variable R : realType.`
outside a Section is an error since Rocq 9.0 (upstream build log on Coq 8.18 shows the
`local-declaration` warning at that line; under Rocq 9.1.1 the raw upstream file fails
with `Error: Use of "Variable" or "Hypothesis" outside sections behaves as
"#[local] Parameter" or "#[local] Axiom".`). Both files carry the repository's marked

added: this file imports `all_ssreflect` BEFORE `all_algebra`, so the ring notations

`GRing.one` of R). This mirrors the root file `putnam_1962_b2.v`, which carries only
compat line (2). Compat line (3) does not apply (no derivative notations).

## 3. The fix

`putnam_1967_a4_corrected.v` differs from `putnam_1967_a4.v` (upstream + compat line)
in exactly one line (apart from the header comment):

```diff
-    : ~exists u : R -> R, forall x : R, 0 <= x <= 1 -> u x = 1 + lambda * \int[mu]_(y in [set y | 0 <= y <= 1]) (u y * u (y - x)).
+    : ~exists u : R -> R, mu.-integrable [set y | 0 <= y <= 1] (constructive_ereal.EFin \o u) /\ forall x : R, 0 <= x <= 1 -> u x = 1 + lambda * \int[mu]_(y in [set y | x <= y <= 1]) (u y * u (y - x)).
```

Two changes in that line:

1. `[set y | 0 <= y <= 1]` -> `[set y | x <= y <= 1]` in the integral: int_x^1 as in the
   problem. The equation now uses u only on [0, 1] (y in [x, 1] and y - x in [0, 1 - x]).
   Lean integrates over `Set.Ioo x 1`; the endpoints are Lebesgue-null, so the closed
   interval (kept in upstream's `[set y | _ <= y <= 1]` style) gives the same integral.
2. The conjunct `mu.-integrable [set y | 0 <= y <= 1] (constructive_ereal.EFin \o u)`:
   u is Lebesgue integrable on [0, 1] (measurable on [0, 1] and int_[0,1] |u| < +oo),
   Lean's `IntegrableOn u (Set.Icc 0 1)`. `EFin` (the embedding R -> \bar R that
   `integrable` expects) is written with its module prefix because the upstream imports
   do not import `constructive_ereal` (checked: `EFin` alone and `(u y)%:E` are rejected
   on both toolchains, `constructive_ereal.EFin` resolves on both), so no import line had
   to be added.

Why this is faithful and not a weakening of the problem: the problem's equation at
x = 0 contains int_0^1 u(y)^2 dy, which exists as a real number (for a measurable u)
only if u is square-integrable on [0, 1], hence integrable there (Cauchy-Schwarz on a
set of measure 1). So the conjunct excludes no function the problem speaks about; it
only removes the junk-value reading of non-integrable functions. It is also the
weakest natural condition under which the problem's argument works: if u is
integrable on [0, 1], Tonelli gives int_0^1 int_x^1 |u(y)| |u(y - x)| dy dx
= (int_0^1 |u|)^2 / 2 < oo, so for almost every x the Rocq integral is the genuine one.
(Lean's condition is a.e.-strong measurability; the Rocq one is measurability for the
Borel sigma-algebra of `mu`. For a solution of the equation the two agree: if u is
Lebesgue measurable and integrable and satisfies the equation, replace u by a Borel v
equal to it a.e.; the integrals do not change, and x |-> int 1_{x<=y<=1} v(y) v(y - x) dy
is Borel by Tonelli, so u = 1 + lambda * (that function) is Borel on [0, 1].)

Deviation from the Lean statement: only the closed vs open integration interval
(immaterial) and the measurability notion (immaterial, see above). Everything else
(`lambda > 1 / 2`, the closed interval for x, `u y * u (y - x)`, `~exists`) is
upstream's text and matches Lean and the informal statement. Nothing is weakened
relative to the problem; no hypothesis of the problem is dropped.

## 5. Difficulty estimate and proof sketch

**Difficulty: 4 / 5.** The mathematics is two lines; the Rocq proof needs Fubini/Tonelli
on the product of Lebesgue measures, a change of variables (translation and reflection
of Lebesgue measure) and the handling of the Rintegral junk value on a null set of x.

Plan (names from MathComp-Analysis 1.16.0 unless noted):

1. From `mu.-integrable [0,1] (EFin \o u)` get u measurable on [0,1] and
   I := \int[mu]_(x in [0,1]) u x finite; extend by 0 outside [0,1] (`patch`/`\_ D`,
   `integrable_mkcond`).
2. Let h(x, y) := 1_{0<=x<=y<=1} u(y) u(y - x) on R x R (product measure `mu \x mu`).
   Measurability: composition of u with the measurable maps (x, y) |-> y, y - x
   (`measurable_fun` lemmas for pairs, `measurable_funB`).
3. Tonelli (`fubini_tonelli`, `lebesgue_integral_fubini.v`) on |h|: for fixed y the inner
   integral over x in [0, y] of |u(y - x)| equals int_0^y |u(s)| ds by translation and
   reflection invariance of Lebesgue measure (`lebesgue_measureN` for the reflection;
   translation invariance has no library lemma that I found: prove it from
   `lebesgue_measure_unique`, the translated measure agreeing on intervals, or via
   `ge0_integration_by_substitution`-style lemmas); hence
   int |h| = int_0^1 |u(y)| int_0^y |u(s)| ds dy <= (int_0^1 |u|)^2 < +oo, so h is
   integrable on the product (`integrable12ltyP`).
4. Fubini (`Fubini`, `ae_integrable1`): for mu-a.e. x in [0, 1], y |-> h(x, y) is
   integrable, so the Rocq integral in the equation is the genuine one; integrating the
   equation over [0, 1] (the junk values live on a null set, `ae_eq_integral`) gives
   I = 1 + lambda * int h.
5. int h = I^2 / 2: by Fubini in the other order and the substitution s = y - x,
   int h = int_{0<=s<=y<=1} u(s) u(y); by symmetry (swap the coordinates, Fubini again)
   the two triangles have equal integrals and the diagonal is null, so
   2 int h = (int_0^1 u)^2 = I^2.
6. Real algebra: lambda I^2 - 2 I + 2 = 0 with lambda > 1/2 is impossible:
   lambda I^2 - 2 I + 2 = lambda (I - 1/lambda)^2 + 2 - 1/lambda > 0 (`lra`/`nra` after
   multiplying by lambda).

Library facts needed: product measures and Fubini/Tonelli (`fubini_tonelli`, `Fubini`
exist in both 1.0.0 and 1.16.0), reflection invariance (`lebesgue_measureN`, 1.16.0
only) and translation invariance of Lebesgue measure (to be proved; the uniqueness lemma
`lebesgue_measure_unique` is also 1.16.0 only), integrals over null sets. Expected `Print Assumptions`: `R` and the three `boolp` axioms. A proof may be
much easier on 1.16.0 than on 1.0.0 and might compile only on Rocq 9.1.
